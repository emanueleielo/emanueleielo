# Hi, I'm Emanuele Ielo 👋

**AI Engineer and Forward Deployed Engineer** based in Rome, Italy. I build AI agents and developer tooling with **LangChain**, **LangGraph** and **DeepAgents**, with a focus on **context engineering** and **middleware**.

## Featured projects

| Project | Problem it solves | Stack |
|---|---|---|
| [**CianaParrot**](https://github.com/emanueleielo/ciana-parrot) ([site](https://cianaparrot.dev) · [docs](https://docs.cianaparrot.dev)) | A self-hosted personal AI assistant with multi-channel chat (Telegram), scheduled autonomous tasks, MCP integration and extensible skills, configured from a single YAML file. | Python, DeepAgents, LangChain, LangGraph, Docker, MCP |
| [**compact-middleware**](https://github.com/emanueleielo/compact-middleware) ([PyPI](https://pypi.org/project/compact-middleware/)) | Long-running agents run out of context window. Multi-level context compaction, inspired by Claude Code's compaction pipeline, as a drop-in DeepAgents middleware. | Python, DeepAgents, LangChain, LangGraph |
| [**advisor-middleware**](https://github.com/emanueleielo/advisor-middleware) ([PyPI](https://pypi.org/project/advisor-middleware/)) | Pairs a fast, cheap executor model with a stronger advisor model that is consulted only on critical decisions (open-source take on Anthropic's Advisor Strategy). | Python, DeepAgents, LangChain, LangGraph |
| [**deepagents-open-lovable**](https://github.com/emanueleielo/deepagents-open-lovable) | Generating complete React apps from natural-language conversations, with live preview and specialized sub-agents. | Python, LangGraph, DeepAgents, React, Vite, Tailwind CSS |
